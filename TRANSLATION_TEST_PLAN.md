# Plan de Test pour la Traduction Multilingue

## Objectif
Vérifier l'exhaustivité et la précision de la traduction dans l'outil d'évaluation d'impact RGPD.

## Étapes de Test

### 1. Interface Générale
- [ ] Tous les textes statiques sont traduits
- [ ] Les titres sont corrects dans les deux langues
- [ ] Le sélecteur de langue fonctionne correctement

### 2. Formulaire de Saisie
- [ ] Tous les labels sont traduits
- [ ] Les options de sélection sont traduites
- [ ] Les messages d'erreur sont traduits
- [ ] Les tooltips (s'il y en a) sont traduits

### 3. Sections Spécifiques à Vérifier
- [ ] Types de violation de données
- [ ] Types de données personnelles
- [ ] Niveaux d'impact
- [ ] Secteurs d'activité
- [ ] Mesures prises

### 4. Résultats et Notifications
- [ ] Titres des résultats
- [ ] Messages de notification RGPD
- [ ] Explications détaillées
- [ ] Boutons d'action

### 5. Compatibilité et Persistance
- [ ] La langue persiste après rechargement
- [ ] Aucun texte non traduit n'apparaît
- [ ] La mise en page reste cohérente dans les deux langues

## Instructions de Test
1. Ouvrir l'application
2. Basculer entre français et anglais
3. Remplir un formulaire complet dans chaque langue
4. Générer un document
5. Vérifier la cohérence et la lisibilité

## Problèmes Potentiels à Surveiller
- Textes tronqués
- Traductions littérales peu naturelles
- Problèmes de mise en page
- Incohérences de style
