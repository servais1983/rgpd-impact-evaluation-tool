# Outil d'Évaluation d'Impact RGPD

Cet outil aide les organisations à déterminer si une notification à l'Autorité de Protection des Données (APD) est nécessaire suite à une violation de données, et prépare les documents requis selon le type de données qui auraient pu être exfiltrées et les articles du RGPD qui s'appliquent.

## Fonctionnalités

- Évaluation rapide de la nécessité de notifier l'APD
- Identification des articles du RGPD applicables selon le type de données compromises
- Génération automatique des documents de notification
- Guide étape par étape pour la gestion d'incidents liés aux données personnelles
- Documentation des mesures à prendre après une violation de données

## Comment utiliser l'outil

1. Remplissez le questionnaire concernant l'incident de sécurité
2. L'outil évaluera si une notification est nécessaire
3. Si oui, l'outil vous guidera pour préparer les documents requis
4. Suivez les recommandations pour limiter l'impact et prévenir de futurs incidents

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/servais1983/rgpd-impact-evaluation-tool.git

# Naviguer dans le répertoire
cd rgpd-impact-evaluation-tool

# Installer les dépendances
npm install

# Lancer l'application
npm start
```

## Contexte légal

Cet outil est basé sur les exigences du Règlement Général sur la Protection des Données (RGPD), notamment :

- Article 33 : Notification d'une violation de données à caractère personnel à l'autorité de contrôle
- Article 34 : Communication d'une violation de données à caractère personnel à la personne concernée
- Article 35 : Analyse d'impact relative à la protection des données

## Avertissement

Cet outil est fourni à titre informatif et ne remplace pas un avis juridique professionnel. En cas de doute, consultez un avocat spécialisé en droit des données personnelles.
